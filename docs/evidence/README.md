# Evidence

This folder contains technical evidence related to local execution, validation, functional baselines, and academic review artifacts for RematePOS.

The evidence documents local validation work. It does not describe a production deployment and must not include real secrets, environment files, dumps, backups, full logs, or generated artifacts.

- [HU-103_LOCAL_EXECUTION_EVIDENCE.md](HU-103_LOCAL_EXECUTION_EVIDENCE.md): complete local execution evidence for database, backend, API Gateway, frontend, checkout, cash payment, and invoice lookup validation.
