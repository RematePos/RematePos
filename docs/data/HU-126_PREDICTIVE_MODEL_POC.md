# HU-126 - Predictive Model Proof Of Concept

## Purpose

This document describes the HU-126 predictive model proof of concept for RematePOS.

The goal is to provide a minimal, honest, reproducible academic example of data transformation, feature engineering, model training, and metric calculation using synthetic non-sensitive sales data.

This proof of concept is not a production model.

## Relationship With HU-125

HU-125 audited the RematePOS repositories and found that:

- no trained predictive model existed;
- no versioned dataset existed;
- no model metrics existed;
- no prediction endpoint existed.

HU-126 addresses that gap with a controlled POC. It does not claim to predict real business sales.

## Dataset

Dataset path:

```text
analytics/data/sample_sales_data.csv
```

Dataset characteristics:

- synthetic;
- non-sensitive;
- small and versionable;
- between 100 and 200 records;
- no customer names;
- no identification numbers;
- no phone numbers;
- no emails;
- no addresses.

## Dataset Columns

| Column | Description |
| --- | --- |
| `sale_date` | Synthetic sale date |
| `product_id` | Synthetic product identifier |
| `category` | Product category |
| `quantity_sold` | Units sold |
| `unit_price` | Unit price |
| `stock_available` | Stock available at sale time |
| `payment_method` | Payment method |
| `return_flag` | Whether the item had a return marker |

## Transformations

The training script performs:

1. Required column validation.
2. `sale_date` conversion to datetime.
3. Feature derivation.
4. Categorical encoding.
5. Train/test split.
6. Baseline model training.
7. Metric generation.

## Derived Variables

| Variable | Description |
| --- | --- |
| `day_of_week` | Day of week extracted from `sale_date` |
| `month` | Month extracted from `sale_date` |
| `is_weekend` | Weekend flag derived from `day_of_week` |
| `sale_total` | Target value: `quantity_sold * unit_price` |

## Model

Model used:

```text
RandomForestRegressor
```

The model is used as a baseline for academic demonstration. No `.pkl`, `.joblib`, `.h5`, `.keras`, `.onnx`, `.pt`, or `.pth` artifact is saved in this HU.

## Execution Command

Install dependencies:

```powershell
python -m pip install -r analytics/requirements.txt
```

Run training:

```powershell
python analytics/scripts/train_sales_prediction_model.py
```

## Limitations

- The dataset is synthetic and does not represent real RematePOS business history.
- The target variable is derived from transaction-level fields, so this POC is primarily useful to demonstrate the process.
- The model is not deployed.
- The model is not integrated with backend or frontend.
- The model should not be used for commercial decisions.
- More historical data would be required for real forecasting.
