# Analytics

This folder contains the RematePOS predictive model proof of concept for HU-126.

The proof of concept uses a small synthetic, non-sensitive sales dataset to demonstrate:

- dataset creation;
- data validation;
- feature engineering;
- baseline model training;
- metric generation;
- honest documentation of limitations.

This is not a production model and is not integrated with the backend or frontend.

## Structure

```text
analytics/
  README.md
  requirements.txt
  data/
    sample_sales_data.csv
  scripts/
    train_sales_prediction_model.py
  results/
    model_metrics.json
    model_metrics.md
```

## Dataset

The dataset in `analytics/data/sample_sales_data.csv` is synthetic. It does not contain:

- customer names;
- identification numbers;
- phone numbers;
- emails;
- addresses;
- real private business data.

## Install Dependencies

```powershell
python -m pip install -r analytics/requirements.txt
```

## Run The POC

```powershell
python analytics/scripts/train_sales_prediction_model.py
```

## Results

The script writes:

- `analytics/results/model_metrics.json`
- `analytics/results/model_metrics.md`

Metrics are generated by the script and must not be invented manually.

## Scope

This POC is academic and reproducible. It is not a production forecasting system and does not persist a serialized model artifact.
